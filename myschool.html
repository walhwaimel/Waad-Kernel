MySchool Database

A school database system for academic records, enrollments, and administration workflows.نظام قاعدة بيانات مدرسية للسجلات الأكاديمية والتسجيل وسير العمل الإداري.

03

Project Overviewنظرة عامة على المشروع

MySchool Database models core school entities and their relationships for clearer academic data management.ينمذج MySchool Database كيانات المدرسة الأساسية وعلاقاتها لإدارة البيانات الأكاديمية بوضوح أكبر.

Problem Statementبيان المشكلة

Manual school records can create duplicated data, unclear enrollment history, and inconsistent administration workflows.قد تؤدي السجلات المدرسية اليدوية إلى تكرار البيانات وغموض تاريخ التسجيل وعدم اتساق الإجراءات الإدارية.

Why It Was Builtلماذا بُني المشروع

It was built to practice relational modeling and create a structured foundation for school management features.بُني للتدرب على النمذجة العلائقية وإنشاء أساس منظم لمزايا إدارة المدرسة.

Development Processعملية التطوير

Requirements were mapped into entities, relationships, constraints, normalization decisions, and SQL implementation checks.حُولت المتطلبات إلى كيانات وعلاقات وقيود وقرارات تطبيع وفحوصات تنفيذ SQL.

Tools and Technologiesالأدوات والتقنيات

ERD, SQL, relational schema design, normalization, constraints, query planning.

UML Diagrams / Architectureمخططات UML / البنية

The architecture centers on Student, Teacher, Course, Enrollment, Department, and Administration entities connected through relational constraints.تتمحور البنية حول كيانات Student وTeacher وCourse وEnrollment وDepartment وAdministration المرتبطة بقيود علائقية.
